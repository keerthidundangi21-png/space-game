K20: ALIEN SURVIVAL — COMPLETE GODOT PROJECT

Included in this package:
- Main.tscn and project.godot
- Complete assets folder (hero images, background, aliens, music and sound effects)
- Updated main.gd with How to Play layout and profile/save-slot explanations

OPEN IN GODOT 4:
1. Extract this ZIP to a folder.
2. Open Godot 4.
3. Click Import and choose project.godot inside this folder.
4. Open the project and press F6/F5 (Run Project).

Controls: A/D or Left/Right = move; Space/W/Up = jump; F/Enter = fire; E = weapon upgrade; 1-4 = weapon; M = music; Esc = menu.

Save slots: Player 1, Player 2 and Player 3 each use a separate save file in Godot's user data folder.

Note: The project package was assembled and file paths checked. It was not run in the Godot editor in this environment, so please test it in Godot 4 and share any error screenshot if one appears.
